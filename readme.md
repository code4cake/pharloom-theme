# Pharloom

Unofficial dark theme inspired by Hollow Knight: Silksong (Pharloom).
Fan palette only — not affiliated with Team Cherry.

## Install (local)

Cursor / VS Code → Command Palette → **Developer: Install Extension from Location** → select this folder.

Then: **Preferences: Color Theme** → **Pharloom Dark**.

## iTerm2

Import `terminal/Pharloom.itermcolors`:
iTerm2 → Settings → Profiles → Colors → Color Presets → Import…

## Windows Terminal / PowerShell

1. Copy the scheme from `terminal/Pharloom.windows-terminal.json`
   into Windows Terminal `settings.json` → `schemes`.
2. Set the PowerShell profile `"colorScheme": "Pharloom"`.

VS Code / Cursor: install this extension folder (or clone the repo)
and pick **Pharloom Dark** — same on Windows.
